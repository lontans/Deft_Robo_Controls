Working Modes

MIT Mode
The MIT mode is designed to be compatible with the original MIT mode, enabling seamless
switching while allowing flexible setting of the control range (P_MAX, V_MAX, T_MAX). The
electronic speed controller converts the received CAN data into control variables for
calculation to obtain the torque value as the current reference of the current loop, and the
current loop finally reaches the given torque current according to its adjustment law. Its
control schematic diagram is as follows:




Multiple control modes can be derived from the MIT mode. For example, when kp = 0 and
kd is not 0, giving v_des can realize uniform speed rotation; when kp = 0 and Kd = 0 ,
giving t_ff can realize given torque output.
Note: When controlling the position, kd cannot be set to 0, otherwise the motor will oscillate
or even lose control.

Position-Speed Mode
The position cascade mode is a mode using three-loop series control. The position loop is
the outermost loop, whose output is used as the given value of the speed loop, and the
output of the speed loop is used as the given value of the inner current loop to control the
actual current output. Its control schematic diagram is as follows:




 p_des is the target position for control, and v_des is used to limit the maximum absolute
speed during movement.




                                               7
If the control parameters recommended by the debugging assistant are used in the position
cascade mode, good control accuracy can be achieved, and the control process is relatively
smooth, but the response time is relatively long. In addition to v_des , the relevant
parameters that can be configured also include acceleration/deceleration. If additional
oscillations occur during the control process, the acceleration/deceleration can be increased.


Note: The units of p_des and v_des are rad and rad/s respectively, and the data type is
float. The damping factor must be set to a non-zero positive number, and the notes of the
speed mode can be referred to.



Speed Mode
The speed mode can make the motor run stably at the set speed, and its control schematic
diagram is as follows:




Note: The unit of v_des is rad/s, and the data type is float. If you need to use the
debugging assistant to automatically calculate parameters, you need to set the damping
factor to a non-zero positive number. Usually, the value is between 2.0 and 10.0. Too small
a damping factor will cause speed oscillation and large overshoot, while too large a damping
factor will result in a longer rise time. The recommended setting value is 4.0.

Usage
Control uses the CAN standard frame format with a fixed baud rate of 1 Mbps, and can be
divided into receive frames and feedback frames according to functions. The receive frame
is the received control data used to realize command control of the motor; the feedback
frame is the motor's status data sent to the upper controller. According to different modes
selected by the motor, the frame format definition and frame ID of the receive frame are
different, but the feedback frames under various modes are the same.

Feedback Frame
The feedback frame ID is set by the debugging assistant (Master ID), with a default of 0,
mainly feeding back the motor's position, speed, and torque information. Its frame format
definition is as follows:

Where:
• ID represents the controller ID, taking the lower 8 bits of CAN_ID.
• ERR represents the fault, with the corresponding fault types being:
    ◦ 8 -- Overvoltage;
    ◦ 9 -- Undervoltage;
    ◦ A -- Overcurrent;
    ◦ B -- MOS overtemperature;
    ◦ C -- Motor coil overtemperature;
    ◦ D -- Communication loss;
    ◦ E -- Overload;
• POS represents the motor's position information.
• VEL represents the motor's speed information.
• T represents the motor's torque information.
• T_MOS represents the average temperature of the MOS on the driver, in ℃.

• T_Rotor represents the average temperature of the motor's internal coil, in ℃.

Position, speed, and torque use a linear mapping relationship to convert floating-point data
into signed fixed-point data, where position uses 16-bit data, and speed and torque both use
12-bit data.

Frame ID is equal to the set CAN ID value.
• P_des: Position given value.
• V_des: Speed given value.
• Kp: Position proportional coefficient.
• Kd: Position differential coefficient.
• T_ff: Torque given value.
Each parameter conforms to the mapping relationship in the previous section, where the
ranges of p_des, v_des, and t_ff can be set by the debugging assistant. The range of Kp is
[0, 500], and the range of Kd is [0, 5].
A standard CAN data frame has only 8 bytes. The MIT control command format combines
five parameters: Position, Velocity, Kp, Kd, and Torque into 8 bytes by bit. Among them,
Position occupies 2 bytes (16 bits), and Velocity, Kp, and Kd each occupy 12 bits.

Frame ID is the set CAN ID value plus an offset of 0x100.
• P_des: Position given value, floating-point type, with lower bits first and higher bits later.
• V_des: Speed given value, floating-point type, with lower bits first and higher bits later.

Using Damiao Technology Debugging Assistant
Use the Damiao Technology USB-to-CAN debugging tool to connect the computer and the
motor, and set parameters and upgrade firmware for the motor through the Damiao
Technology assistant.
Connect the motor's debugging serial port to the PC through a GH1.25 connection cable -
3pin, and connect the CAN communication terminal in the motor's power interface to the
USB-to-CAN debugging tool through an XT30(2+2)-F plug connection cable. Then, set
parameters and upgrade firmware for the motor through the Damiao Technology debugging
assistant.
After the motor's serial port, CAN port, and power interface are connected, open the Damiao
Technology debugging assistant on the computer, select the corresponding serial port
device, and open the serial port. Then, power on the motor, and the serial port will print
information, with "Control Mode" indicating the current driving mode.
For detailed debugging procedures, refer to the Debugging Assistant Instruction Manual
(Damiao Drive Control Protocol) V1.3.pdf.Download link:
http://www.dmbot.cn/forum.php?mod=viewthread&tid=364&extra=page%3D1
